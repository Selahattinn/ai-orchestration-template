# Task Examples

## Example 1: New API Surface

Input:
- "Design a v1 API for project onboarding and define error handling."

Expected flow:
- `api_designer` -> `go_idiom_guard` -> `architect` -> `test_strategist` -> `style_guard` -> `reviewer`

Expected artifacts:
- API contract summary
- Go idiom compliance notes
- Architecture topology notes
- Test matrix
- Style compliance report
- Final review decision

## Example 2: Contract Review Only

Input:
- "Review current service contract and propose idiomatic Go boundary updates."

Expected flow:
- `go_idiom_guard` -> `architect` -> `style_guard` -> `reviewer`

Expected artifacts:
- Boundary recommendations
- Dependency and failure-mode notes
- Style violation and fix list
- Risk-ranked review findings

## Example 3: High-Risk Security Constraints

Input:
- "Design admin APIs with strict auditability and sensitive data controls."

Expected flow:
- `api_designer` -> `architect` -> `reviewer`

Expected artifacts:
- Security-sensitive assumptions
- Policy-aligned decision log
- Human-approval checkpoints
